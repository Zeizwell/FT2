# Диск — FAT32 (подготовка)

## Драйвер

- **Исходник:** `drivers/fat32/` — копия github.com/andrewinsidelazarev/FAT32-Driver-ZX-Evolution,
  коммит `6e0de6a` (MIT, `drivers/fat32/LICENSE`).
  - Взяты `src/`, `include/`, `ports/`, README и VALIDATION автора.
  - Тесты и сборка на Python не взяты: Python у нас нет, собираем sjasmplus напрямую.
  - Наши правки в драйвере пока не нужны. Понадобятся — делаем прямо в этой копии.
- **Сборка** (`build.bat`, до основной):
  - `drivers/fat32/src/main.asm` → `build/fat32.bin` (код, 15979 байт из 16К);
  - `ports/sdzc.asm` → `build/port_sdzc.bin` (порт SD Z-Controller `#57/#77`, 577 байт).
- **В SPG:**

  | Страница | Что | Окно на время вызова |
  |---|---|---|
  | `#14` | код драйвера (`fat32.bin`, входы `#4000 + номер×3`) | 1 |
  | `#15` | рабочая память драйвера: нули + порт SD-ZC на `#3900` (`srs/fatwork.bin`, делает `main.asm`) | 0 |
  | `#18` | наш переходник (`srs/disk.asm` → `srs/disk.bin`) | 2 |

## Как вызывать (`srs/diskcall.asm`, в коре)

Драйвер хочет окна 0 и 1 себе, а у нас там коре и тулза. Поэтому сам вызов идёт из
переходника в окне 2:

1. `Disk_Call` (коре): `DI`, переходник в окно 2, прыжок в него.
2. Переходник:
   - ставит свой стек;
   - копирует имена к себе (драйверу они нужны в `#8000..#BFFF`);
   - отдаёт окна 0/1 драйверу и вызывает вход;
   - возвращает окна 0/1.
3. `Disk_Ret` (коре): окно 2 как было, результат в регистрах, `EI`.

| Регистр | Вход |
|---|---|
| IXL | номер входа драйвера (`DK_*` в `diskcall.asm`, полный список — `drivers/fat32/include/fat32.inc`) |
| IXH | сколько имён скопировать: 0; 1 — по HL; 2 — по HL и DE (переименование) |
| A, BC, DE, HL | параметры драйвера |
| окно 3 | буфер данных (чтение / запись) — ставит вызывающий |

Выход: AF, BC, DE, HL — что вернул драйвер; IX и IY целы; окна 0..3 как были.

- На время вызова прерывания запрещены: в окне 0 у драйвера буферы, IM1 туда не
  попадёт. Музыка на это время стоит, как и решали.
- `Disk_Mount` — подключить порт SD-ZC (`#3900`), инициализировать карту, найти
  FAT32. `Z` — готово.

## Проверка (временно)

**Ctrl+D** в виде паттерна:
- монтирует карту;
- ищет в корне папку `TMPFT` (туда `build.bat` кладёт `ft2.spg`);
- только чтение.

В отладочной строке внизу — `D:AA FF`, это A и флаги драйвера:

| Что видно | Значит |
|---|---|
| `D:01 xx`, бит Z в FF = 0 | найдено — всё работает |
| `D:00`, бит Z = 1 | смонтировано, но папки нет |
| бит C в FF = 1 (FF нечётный) или ненулевой A после монтирования | ошибка (коды `FAT32_*` в `fat32.inc`) |
| `D:FF FF` | ещё не нажимали |

В Unreal карта — образ `tools/unreal/wc.img`.
Автор драйвера пишет, что модель SD в Unreal ошибается при **записи** (CMD24) — для
записи проверять на железе или в Xpeccy.

## Тулза диска (`srs/diskview.asm`, страница `#1A`)

Вкладка **Disk** в шапке. Коре зовёт тулзу из `SV_TOOL`: вид паттерна ставит туда
`PAGE_TOOL_DISK` и выходит, тулза диска по вкладке **Pattern** - обратно.

- Строки 0..3 - копия шапки из её буфера (кликается только вкладка Pattern).
- Слева каталог: папки, потом файлы (имя, размер или `<DIR>`, дата). Клик - выбрать,
  двойной клик / Enter - открыть, колесо и стрелки, PgUp/PgDn, Home/End, Backspace -
  в папку выше. Каталог - в странице `#0F` (`PAGE_DIRLIST`, до 248 записей, имя до 55 знаков).
- Справа: **Name** (поле ввода, Tab - фокус каталог <-> Name), тип, размер, Song / By
  (FT2 и PT3 - из первого сектора файла), кнопки **Load** / **Save**, сообщение.
- **Load** - FT2 и PT3 (импорт - `srs/pt3imp.asm`, что куда - в его шапке). Плеер - стоп, файл - в
  буфер `#1E..` (`PAGE_FILEBUF`), оттуда страница трека, инструменты, паттерны; `SV_SONG_NEW` = 1 -
  вид паттерна при входе перечитывает трек (`Song_Reload`).
- **Save** - под именем из Name (нет точки - `.ft2`). Файл уже есть - пишется
  `FT2TMP.$$`, потом старый удаляется, временный переименовывается.

### Файл FT2

| Часть | Размер |
|---|---|
| страница трека (заголовок `FT2S`, ордер, каталоги) | 16К |
| страница инструментов и орнаментов | 16К |
| паттерны 0..63, что есть в каталоге: роу 0..длина-1, только данные | 112 байт на роу |

### Флаги драйвера (не путать)

- запись каталога (`NXTETY`): +0 кластер, +4 размер, +8 дата, +10 время, +12 флаг
  (`#00` - папка, `#10` - файл), +13 имя;
- поиск, удаление (`FIND`, `DELETE`): `#10` - папка, `#00` - файл.

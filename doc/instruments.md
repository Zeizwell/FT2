# Инструменты и орнаменты — анализ и формат FT2

Источники:
- FTC — `doc/formats/ftc.md` (восстановлен по плееру 1.15 и проверен на модуле);
- PT3 / Vortex Tracker II — `doc/formats/pt3.md`, `trackers/vt/Tracker manual.txt`;
- Bitphase — исходники `paator/bitphase`:
  - `src/lib/chips/ay/mixer-macros.ts` — строка инструмента;
  - `ay-timer-macros.ts`, `instrument.ts` — таймерные FX;
  - `src/lib/models/project.ts` — таблицы.

## 1. Как у них

### Инструмент (сэмпл) — строка на тик

| | FTC | PT3 / VT | Bitphase |
|---|---|---|---|
| строк | до 80 (формат до 256) | 64 (формат 255) | до 512 |
| цикл | loop + end, всегда зациклен | loop + end, всегда зациклен | loop |
| байт на строку | 5 | 4 | объект |
| тон вкл/выкл | да (маска) | да (маска) | да |
| смещение тона | ±2048 (12 бит), накопление | ±32767, накопление | −4096..4095, накопление |
| шум вкл/выкл | да | да | да |
| смещение шума | 0..31, накопление | 0..31 (или огибающая) | −31..31, накопление |
| огибающая вкл/выкл | да (маска) | да (маска) | да |
| смещение огибающей | ±127, накопление | ±15 (общее поле с шумом), накопление | −255..255, накопление |
| громкость | 0..15 | 0..15 | 0..15 |
| слайд громкости | ±1 за проход | ±1 за проход | вверх / вниз |
| ретриггер огибающей | командой 500 | нет | в строке (флаг) |

Как устроено:
- В PT3 одно поле — это либо шум, либо смещение огибающей, в зависимости от маски
  шума. Из-за этого баг: смещение огибающей влияет даже без огибающей.
- В FTC шум и огибающая — отдельные поля, у каждого своё накопление.
- В Bitphase поля независимые, плюс ретриггер огибающей прямо в строке.

### Таймерные FX (только Bitphase, у нас — FX-номер инструмента)

- **SID** — меандр громкостью: шаги `timerWaveform` (1..32 значения), скважность
  PWM 0..100 %, свип скважности (min, скорость, форма: треугольник, синус, пила,
  меандр, стартовая фаза), «сохранять при новой ноте».
- **Syncbuzzer** — перезапуск огибающей таймером.
- **FM / Env FM** — шаги частоты таймера: в полутонах (−127..128) или в периоде
  (±4095), свой цикл.
- **Детюн таймера** — полутон и период.

**FX у FT2 (решено 2026-10-11)** — отдельный инструмент таймерных эффектов, как классик-вид Bitphase:
- до 32 FX на трек (`FXS_MAX`), у FX до **32 строк** (по тику) и цикл, как у инструмента; инструмент хранит
  номер FX (`INS_FX`), нота запускает FX с первой строки;
- **строка FX = 12 байт = регистры канала карты `#C3`–`#CE`** (`Trinity/doc/ay-ports-map.md`, п.5а): FLAGS, PWM, свип,
  3 × (детюн в полутонах, сырой детюн, номер таблицы) для Mix (SID / Sync), FM, Env FM;
- **таблицы таймера** — до 32 на трек, заголовок (длина 1..16, цикл) + до 16 шагов по байту;
- память: 32 × 32 × 12 = 12К + 32 × 17 = 0.5К — на странице FX трека;
- исполняет плата (RP); без неё FX молчит. Эмуляция — устройство Trinity в нашем Unreal.

### Орнамент — строка на тик

| | FTC («имидж») | PT3 / VT | Bitphase («таблица») |
|---|---|---|---|
| штук | 32 + пустой | 15 + пустой | без лимита |
| строк | до 80 | 64 (VT до 255) | любое |
| смещение ноты | полутоны со знаком, накопление | полутоны со знаком | полутоны |
| шум | смещение шума, накопление | нет | нет |
| цикл | loop + end | loop + end | loop |
| накопление всей таблицы | — | — | флаг `additive` |

В Bitphase таблица ещё служит параметром эффектов: варианты `AXTY`, `VXTY`, `1XTY`…
берут значения из неё.

## 2. Формат FT2 в памяти — как в FTC (константы — `sdk/plugin.asm`)

Решение пользователя: брать формат Fast Tracker. В нём есть всё нужное, и свободные
биты тоже. Тону хватает 12 бит — больше регистр AY не держит.

### Инструменты и орнаменты — по своей странице 16К (2026-11-09)

32 инструмента по 100 строк и 32 орнамента по 100 строк. У трека две страницы: инструменты — `Trk_Ins`
(`SH_INS_PAGE`), орнаменты — `Trk_Orn` (`SH_ORN_PAGE`). Блок — 512 байт, адрес — `#80 + 2n` старшим байтом
(окно 2), без умножений. Плеер держит в окне 3 страницу инструментов и на чтение орнамента переключает
окно 3 на страницу орнаментов (`SWAPPAGE`), потом обратно. Заголовок блока — рядом с его данными.
Имена инструментов — не в блоке, а в странице трека (`SONG_INS_NAMES`, 32 × 16, сразу за именами FX).

| Где | Что | Размер |
|---|---|---|
| `Trk_Ins`: `n×512` | инструмент n (номер n+1): заголовок 3 + 100 × 5 = 503, номер FX | 32 × 512 = 16К |
| `Trk_Orn`: `n×512` | орнамент n (номер n+1): заголовок 3 + 100 × 2 = 203, имя | 32 × 512 = 16К |
| страница трека `SONG_INS_NAMES` | имена инструментов | 32 × 16 = 512 |

### Заголовок блока — как в FTC

| Смещ | Что |
|---|---|
| +0 | конец (копия +2). Плеер FTC его не читает, это длина для редактора и декомпилятора |
| +1 | строка цикла |
| +2 | последняя строка (длина − 1) |
| +3 | строки |

### Инструмент: строка 5 байт (FTC) + ретриггер

| Байт | Биты | Что |
|---|---|---|
| 0 | 7 / 6 / 4..0 | шум накоплением / шум ВЫКЛ / смещение шума |
| 1–2 | 0..11 | смещение тона, 12 бит |
| | 2: 7 / 6 | тон накоплением / тон ВЫКЛ |
| | 2: 4 | **ретриггер огибающей** (в FTC свободен) |
| 3 | 7 / 6 | огибающая накоплением / огибающая ВКЛ |
| | 5 / 4 | слайд громкости / вниз |
| | 3..0 | громкость |
| 4 | | смещение периода огибающей со знаком (вычитается из периода) |

Свободны ещё бит 5 байта 0 и бит 5 старшего байта тона.

Хвост блока:

| Смещ | Что |
|---|---|
| +503 | номер FX (`INS_FX`; FX — отдельные объекты) |

Имя инструмента — в странице трека (`SONG_INS_NAMES + n×16`), 16 знаков.

### Орнамент: строка 2 байта (имидж FTC)

| Байт | Биты | Что |
|---|---|---|
| 0 | 7 / 6 / 4..0 | шум накоплением / нота накоплением / смещение шума |
| 1 | | смещение ноты, полутоны со знаком |

Хвост: +208 — имя, 16 знаков (`ORN_NAME`).

### Импорт

- **FTC** — байт в байт; длины больше 100 обрезаются; все 32 инструмента и 32 орнамента (1..32) — на свои номера.
- **PT3 / PT2** — 16 орнаментов формата (1..15) — на свои номера, остальные наши пустые.
- **PT3** — поле «шум или огибающая» раскладывается по маске шума.
- **Bitphase** — строки макросов → строки, таблицы → орнаменты, таймерные FX → FX.

## 3. Открыто

- Каталоги `SMP_CATALOG` / `ORN_CATALOG` в странице трека (страница, адрес, длина)
  при одной странице не нужны: вместо них — номер этой страницы в заголовке трека.
  Переделать вместе с заголовком трека (шапка).
- «Огибающая нотой» (автоогибающая с соотношением, как в FT) — флаг инструмента или
  настройка трекера.

## 5. Экран инструментов (Instr) и орнаментов (Orn) — требования пользователя

Раскладку ещё не рисовали — это список того, что на экране обязательно.

- **Список инструментов с названиями:** номер и имя, как у Arkos и Bitphase. Не
  полоса мини-графиков, как у VT. Клик — выбрать.
- **Каталог диска сбоку справа:**
  - библиотека: папка на диске, подпапки свои — Kicks, Snares, Synths…;
  - клик по папке — войти; клик по файлу — прочитать и прослушать;
  - загрузить в текущий номер.
- **Операции:**

  | Кнопка | Что делает |
  |---|---|
  | Load | из библиотеки в текущий номер |
  | Save | текущий в библиотеку файлом, имя файла = имя инструмента |
  | Clone | копия в первый свободный номер, переход на неё |
  | Copy / Paste | через буфер, целиком |
  | Delete | удалить (что именно — ниже) |
  | Clear | одна строка «тон, громкость 15» |
  | Unloop | без цикла: в конце тишина |
  | `<<` / `>>` | соседний номер |
  | Name | имя, 16 знаков |

- **Файл в библиотеке** — тот же блок, что в памяти: заголовок FTC, строки, номер FX,
  имя. Читается байт в байт.
- **Для орнаментов** — то же самое.
- **Открыто:** Delete — освободить номер в треке, удалить файл в библиотеке или оба
  (разные кнопки)?

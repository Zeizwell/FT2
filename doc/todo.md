**Формат FT2 — сделать заново:** сейчас файл — дамп памяти (страница трека 16К + инструменты 16К + роу паттернов
по 112 байт): большой даже для пустого трека, ломается от любой перестановки в памяти, тащит состояние редактора,
FX не пишутся. Нужны два формата:
- **контейнер (редактируемый трек)** — простой: блоки с тегом и длиной (как у maxYMiser `MYM0TRAK` / `MYM1INST`),
  только используемое: заголовок, ордер, паттерны, инструменты, орнаменты, FX и таблицы; незнакомые блоки -
  пропускать (новые версии не ломают старые);
- **скомпилированный (для плеера в демках)** — компактный, ≤ 32К (лимит проекта), со своим плеером (п.17).

**Плеер и импорт:**
- импорт FTC: орнамент зря выключает огибающую (у FT не трогает) — пока не делать;

**Компаратор:** в «Our regs» R13 показан из буфера, даже когда не пишется (эталон — `FF`); сравнение верное, путает только вывод.

**Карта AY FX - перейти на 2 регистра (команда / статус + поток данных), как GS** (обсуждено 2026-10-12): вместо ~20
номеров `#C0..#CF`, `#B8..#BD`. Номера AY - дефицит; эффекты, таблицы, SD, прошивка - командами; пакет = атомарно; запись

сброса лимита.

  на весь паттерн не отменяются. Клавиши: Ctrl+Z — отмена, Ctrl+Shift+Z — повтор (Ctrl+Y занят: удалить строку, как в VT).

  строке, кусок 80 точек DMA копируется в окно и размножается вниз (DMA строка N → N+1 с
  перекрытием). Внизу — полоска-база.
- **Высота:** без огибающей — громкость 0..15 = сколько строк размножить (2 строки на уровень,
  снизу вверх, выше — фон). С огибающей (бит 4 громкости) — во всю высоту: громкость даёт
  генератор огибающей.
- **Огибающая — маска вторым слоем** (T0 — меандр, T1 — маска, цвет 0 прозрачный): заранее
  картинка 16 уровней с растущим периодом; низ под кривой — прозрачный, верх — цветом фона →
  эффект AND. Период — R11/R12, форма — R13: пила и треугольник повторяются, одноразовые формы —
  от записи R13 (счётчик с `Pl_R13W`).
- Тон выключен в микшере — вместо меандра сплошная заливка (видна огибающая). Шум — потом.
- DMA ходит словами (4 точки при 4 бит) — позиция в строке с шагом 4; если заметно, 4 копии строки
  со сдвигом. Цена: ~2.5К DMA на канал за кадр, на 6 каналов ~33K тактов из ~280K.

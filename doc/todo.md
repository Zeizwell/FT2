- Высота — из периода тона канала (плеер пишет ноту как обычно, RP берёт период): частота записей =
  `f_тона × 16`; A-4 ≈ 7 кГц, верх октав — десятки кГц, для RP пустяк.
- Громкость ноты — масштабом таблицы в RP; значения таблицы — линейная амплитуда, RP переводит в
  ближайший уровень AY (шкала логарифмическая — иначе волна кривая).
- Звук «грязнее» Амиги (4 бита, лог. шкала) — это характер Atari ST. Арпеджио / вибрато / портаменто /
  слайды — уже есть командами и орнаментами.
- Нужно: тип эффекта в регистрах AY FX (`doc/ay-ports-map.md` п.5а) + эмуляция в Unreal + режим в
  редакторе FX. Делать в реворке FX.
- **Уточнение:** это не новый механизм, а **SID с таблицей 16 уровней + тон канала выключен**. Высота —
  уже есть: тик таймера = 8·P (полпериода ноты), детюн в полутонах ±127. В ноте: 2 шага — детюн 0,
  4 — +12, 8 — +24, 16 — +36 (каждое удвоение длины +12). Детюн / выключение тона — в пресет.
- Амижный звук интро (AHX / Hively, 4K / 64K — синт или сэмплы генерят при старте): 1) квадрат со свипом
  скважности — **уже есть** (SID + ШИМ + свип); 2) свип фильтра — изобразить сменой таблиц (яркая пила ->
  сглаженная -> почти синус); 3) быстрое арпеджио / вибрато / портаменто — есть. Попросить у Патора
  трек-образец.

## Решения по редактору паттерна (2026-10-11)

- **Бинды** — по `doc/architecture.md` (действия по номерам, таблица по умолчанию, свои — из INI потом);
  умолчания — VT, как в `doc/trackers.md` («Бинды FT2 по умолчанию»). Ctrl+E, Ctrl+T пока свои.
  В Instr / Orn — Insert / Ctrl+I вставить строку, Backspace / Ctrl+Y удалить (клавиатура без Ins).
- **Мышь** в редакторе: клик — курсор в клетку (поле и колонка), протяжка — выделение, Shift+клик —
  от курсора до клика, колесо — роу, Shift / Ctrl + колесо — каналы.
- **Отмена:** 5 шагов (отмена и повтор), только в пределах одного канала: шаг — не больше колонки канала
  (64 роу × 16 байт = 1К), всего до 5К — в куске уже занятой служебной страницы, новой страницы не берём.
  Хранить обратное действие + что пропало (клетка 16 байт, строка трека, затёртый кусок). Операции
  на весь паттерн не отменяются. Клавиши: Ctrl+Z — отмена, Ctrl+Shift+Z — повтор (Ctrl+Y занят: удалить строку, как в VT).
- **Форматы** — только базовые, не 100 штук.

## Осцилляторы (п.25) — план пользователя (2026-10-11)

**Решение (2026-10-11): осциллограф — в отдельный вид**, без нот, шапки и т.п.; окна крупнее и в
рамке (залитый меандр без рамки смотрится плохо). В виде паттерна его больше нет: там он занимал
~треть кадра, отрисовка сдвигалась под луч. Код сохранён, но не подключён (IM1, вид паттерна,
генератор в `main.asm`, страницы `#05`, `#1F`, `#B9`, `#BA`, `#BF` — всё возвращено как до него).
Что в коде уже работает: громкость (заливка нулями сверху + строка меандра, размноженная DMA),
меандр из одной длинной полосы как в индикаторе FT (место = 4*период: вибрато двигает), шум
(8 строк, тон AND шум процессором), огибающая — маска блиттером (`DMA_BLT`: над кривой цвет фона,
под — 0 → псевдо-AND; пила / треугольник, 10 длин), одиночные формы — уровнем по времени от R13.
Не решено: вход (вкладка или клавиша), размер окон (на тайлах ширина 96 — предел TSU 36 тайлов в
строке; шире — графический режим), рамки (текстом под тайлами?), что ещё на экране.

Ниже — исходный план (в виде паттерна).

Где: поверх текста, внизу экрана (слои тайлов TSU над текстом), по окну на канал ~10×4 знакоместа
(80×32 точки), 6 каналов.

- **Тон — меандр.** Заранее — одна длинная строка: меандр с плавно растущим периодом (от 1 до ~40
  точек между фронтами). Каждый кадр по периоду тона канала (регистры плеера) — ближайшее место в
  строке, кусок 80 точек DMA копируется в окно и размножается вниз (DMA строка N → N+1 с
  перекрытием). Внизу — полоска-база.
- **Высота:** без огибающей — громкость 0..15 = сколько строк размножить (2 строки на уровень,
  снизу вверх, выше — фон). С огибающей (бит 4 громкости) — во всю высоту: громкость даёт
  генератор огибающей.
- **Огибающая — маска вторым слоем** (T0 — меандр, T1 — маска, цвет 0 прозрачный): заранее
  картинка 16 уровней с растущим периодом; низ под кривой — прозрачный, верх — цветом фона →
  эффект AND. Период — R11/R12, форма — R13: пила и треугольник повторяются, одноразовые формы —
  от записи R13 (счётчик с `Pl_R13W`).
- Тон выключен в микшере — вместо меандра сплошная заливка (видна огибающая). Шум — потом.
- DMA ходит словами (4 точки при 4 бит) — позиция в строке с шагом 4; если заметно, 4 копии строки
  со сдвигом. Цена: ~2.5К DMA на канал за кадр, на 6 каналов ~33K тактов из ~280K.
- Проверить по Verilog: тайловые слои над текстовым режимом.

## Карта и FT2 — мысли к п.57–60 (Claude, 2026-10-25; вопросы — пользователю)

**п.57 Конвертер на карте.**
- Форматы, которые на Спектруме разбирать тяжело, а RP — легко: `.btp` (gzip + JSON), `.vt2` (текст Vortex),
  `.ym` (сжат LHA), `.sndh` (часто ICE-упакован), `.mod`, `.psg`. PT3 / PT2 / FTC — оставить на Z80 (уже есть).
- Обмен — командой SDK: трекер шлёт файл потоком в карту, карта отдаёт `.ft2` потоком назад + **лог «что не влезло»**
  (лимиты FT2: паттернов 64, инструментов 32, орнаментов 16, роу 64) — показать в логе Disk (`Lg_*`).
- Тот же код — утилита на ПК (тест на хосте, правило `rp-host-test-first`).

**Что ещё карта может для Евы (утилиты).**
- **Распаковка:** zip (deflate), LHA (`.ym`), ICE (`.sndh`), gzip — RP распаковывает, Ева получает готовый файл.
- **SD карты как флешка по USB** (RP-GS — USB mass storage): с ПК закинул музыку кабелем на SD карты, без вынимания.
- **Рендер трека в WAV** на SD (эмуляция AY на RP, ayumi — MIT) — поделиться треком без записи с линейного выхода.
- **Данные для осцилляторов FT2 (п.25):** карта знает точное состояние AY и FX — может отдавать уровни / форму по
  каналам каждый кадр, Z80 только рисует.
- Перекодировка текстов (CP866 / CP1251 / UTF-8) для имён файлов и тегов SNDH / MOD.

**п.58 MOD -> AY.**
- Ноты: период Amiga -> нота -> таблица тонов AY. Эффекты: `0xy` арпеджио -> орнамент, `1xx` / `2xx` слайд,
  `3xx` портаменто, `4xy` вибрато, `Axy` / `Cxx` громкость, `Fxx` скорость, `Bxx` / `Dxx` ордер.
- Сэмплы -> инструменты: диалог «сэмпл N -> инструмент AY / шум / барабан (огибающая)»; по умолчанию короткий
  сэмпл = ударный (шум), длинный с петлёй = тон.
- **Решено (пользователь, 2026-10-25): 4 канала MOD -> TurboSound** (6 каналов AY), ничего не выкидывать — старый
  конвертер резал один канал, это плохо.

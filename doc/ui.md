# Интерфейс FT2: примитивы → элементы → экраны

Решено (пользователь, 2026-10-18): интерфейс строится из **примитивов**, на них — **стандартные элементы**, экраны —
только **таблицы описателей**. Одна вещь — один код и один вид везде (до этого каждый экран рисовал по-своему:
«как будто 10 человек писало»).

Образцы, на которые смотрим: Turbo Vision (DOS), Windows 3.x / 95 диалоги, MilkyTracker.

## Слой 1. Примитивы (коре) — рисуют только они

Экран — текстовая страница TS-Config в окне 3: строка = `#C0 + y`, знаки 0..127, атрибуты +128. Цвет — **только роль**
(`THEME_ATTR + CLR_*`), никаких and / or над атрибутами.

| Примитив | Что делает | Где сейчас |
|---|---|---|
| `PutCh` / `PutStr` / `PutHex2` / `Dec2` / `Put_Dec3` | знак, строка, числа (DE — место, C — цвет) | `srs/text.asm` и др. — есть |
| `Pr_Fill` | прямоугольник знаком цветом роли | **сделать** (сейчас — циклы по месту: `Tool_Clear`, `Win_Draw`) |
| `Pr_Attr` | прямоугольник — только атрибуты (тень, подсветка, курсор) | **сделать** (сейчас — `Wd_Shadow`, `Hd_Hover`, `Ti_Cursor` по-своему) |
| `Pr_Box` | рамка ┌─┐│└─┘ по прямоугольнику | **сделать** (сейчас — `Tool_Box`, `Wd_Line`, `Gb_Draw.line` — три копии) |
| `Pr_HLine` | линия ─ (разделитель ├──┤) | **сделать** |

## Слой 2. Элементы — описатель + рисование + обработчик событий поля

Каждый элемент: **описатель** (данные, что показывать, что делать), **одна процедура рисования** (на примитивах),
**обработчик** события поля (`srs/fields.asm`: нажал / отпустил / клик / повтор / колесо / клавиша / фокус / клик мимо).
Поведение одно: под мышью — подсветка, держат — нажата, клик мимо строки ввода — конец ввода, колесо — где уместно.

| Элемент | Файл | Статус |
|---|---|---|
| окно (заголовок-шахматка с текстом по центру, `WF_INVERT`, тень, свой фон, `WF_CONTEXT`; без крестика) | `srs/window.asm` `Win_Open` | есть |
| меню (окно-список у мыши) | `srs/window.asm` `Win_Menu` | есть |
| группа (рамка с заголовком на верхней линии) | `srs/window.asm` `Gb_Draw` | есть |
| кнопка (серая плашка, тень по флагу) | `srs/button.asm` `Bn_*` | есть |
| поле числа `nn[+][-]` (клик, повтор, колесо) | `srs/spin.asm` `Sp_*` | есть |
| строка ввода текста (курсор, клик, Shift, клик мимо) | `srs/textin.asm` `Ti_*` | есть |
| **скроллбар** (дорожка ▒, ползунок ▓, стрелки ▲▼, колесо) | сейчас `Vsb_*` в `srs/fxedit.asm` — вынести в коре | сделать |
| **список** (строки, выбранная, прокрутка, скроллбар) | сейчас 4 разных: инструменты, FX, каталог Disk, ордер | сделать |
| **переключатель / галочка** (`[ ]` / `[✓]` + надпись) | сейчас: `Hd_Mark`, `Kp`, Compare, Pat.cursor — разные | сделать |
| **вкладки** (выбранная — выделением) | шапка, подвкладки FX, Help Keys / Commands — разные | сделать |
| надпись / значение (роль цвета) | по месту | описателем |

## Слой 3. Экраны — только таблицы

Экран = список полей (`FIELD`) + описатели элементов + своя логика данных. Своего рисования рамок, кнопок, списков
в экране **нет**. Новый экран собирается из таблиц.

**Правила:**
- **попадать легко** (пользователь: «я должен отдыхать в программе, а не целиться»): кликабельная зона — весь
  элемент: подпись вместе со значением, строка списка — на всю ширину своей группы / колонки, кнопка — вся плашка;
  никаких целей в один знак;
- **окно одно и модальное**: пока оно открыто, всё вне его не работает; любой клик мимо — только закрыть окно
  (никакого действия под ним); вложенных окон нет (пользователь, 2026-10-19);
- нужен элемент, которого нет, — сначала сделать его стандартным здесь, потом использовать;
- перенос / переделка экрана — пройти его список полей: у каждого нарисованного элемента есть поле **внутри**
  активного списка (до `db FLD_END`), обработчик его ловит;
- цвета окна — роли `CLR_WIN_*`, шапки — `CLR_TOP_*`, редакторов — `CLR_ED_*`; новых «похожих» ролей не плодить;
- раскладка — по одной линии: подписи по краю своих пунктов, кнопки диалога — справа внизу.

## Порядок работ

1. Примитивы `Pr_Fill`, `Pr_Attr`, `Pr_Box`, `Pr_HLine`; окно, группу, `Tool_Box` — перевести на них.
2. Скроллбар — в коре, FX и Disk — на него.
3. Список — в коре (со скроллбаром), FX, Instr / Orn, Disk — на него.
4. Переключатель / галочка, вкладки.
5. Load / Save окном (туду п.43) — уже целиком из элементов.

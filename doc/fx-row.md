# Строка FX — формат (реворк FX, 2026-10-17)

Что лежит в строке FX-инструмента и что уходит в карту (пакет `ROW`, `doc/ay-ports-map.md` п.5а).
Собрано из решений `doc/todo.md` (реворк FX) и `doc/bitphase-fx.md`; раскладка бит — предложение, утвердить.
Сейчас в коде старый формат (12 байт + 2 байта свипа, таблицы с заголовком длины) — переводится в реворке.

## Что уже решено (источник)

- Строка FX — **16 байт**: 14 данных + 2 запас; страница FX — только строки (32 FX × 32 строки × 16 = 16К).
- Эффекты строки: **Mix** (SID или бузер / Sync), **FM**, **Env FM** — у каждого свой таймер, своя таблица и длина.
- Таймер **всегда за тоном** канала (FOLLOW / TAKE убраны).
- **Таблицы:** 256 номеров (0..255), в каждой ровно **16 значений**, без заголовка и без цикла; **длина — в строке**
  (4 бита на эффект, 1..16 шагов). Номера выдаёт редактор, музыкант их не видит.
- **PWM и свип — только когда у Mix таблица из 2 шагов** (как Bitphase). Иначе шаги одной длины.
- Скважность — **16 ступеней 0..50 %** (`n · 50 / 15`; `d` и `100 − d` звучат одинаково).
- Свип: **фаза 256 шагов**, скорость = прибавка к фазе за кадр. **Форма свипа — номер таблицы** (16 точек кривой).
- Форма и стартовая фаза свипа, «не перезапускать» — **на весь FX** (заголовок FX), не в строке.

## Строка FX (16 байт, хранение)

| Смещ | Биты | Поле | Значения |
|---|---|---|---|
| 0 | 1..0 | Mix: режим | `00` выкл, `01` SID, `10` Sync (бузер), `11` резерв |
| 0 | 2 | FM вкл | |
| 0 | 3 | Env FM вкл | |
| 0 | 4 | резерв (был FOLLOW — убран) | 0 |
| 0 | 5 | шаги FM — в единицах периода | 0 — в полутонах |
| 0 | 6 | шаги Env FM — в единицах периода | 0 — в полутонах |
| 0 | 7 | резерв | 0 |
| 1 | 7..4 | PWM max | ступень 0..15 → `n · 50 / 15` % |
| 1 | 3..0 | PWM min | ступень 0..15; действует только при свипе |
| 2 | 7..0 | скорость свипа | 0 — свипа нет (скважность = max); 1..255 — прибавка к фазе за кадр (цикл = 256 / скорость кадров: 1 → ~5 с, 64 → 4 кадра) |
| 3 | 7..0 | Mix: детюн, полутоны | со знаком −128..127 (частота таймера × `2^(−n/12)`) |
| 4 | 7..0 | Mix: детюн сырой | со знаком −128..127, прибавка к периоду таймера |
| 5 | 7..0 | Mix: номер таблицы | 0..255 |
| 6 | | FM: детюн, полутоны | как байт 3 |
| 7 | | FM: детюн сырой | как байт 4 |
| 8 | | FM: номер таблицы | 0..255 |
| 9 | | Env FM: детюн, полутоны | как байт 3 |
| 10 | | Env FM: детюн сырой | как байт 4 |
| 11 | | Env FM: номер таблицы | 0..255 |
| 12 | 3..0 | Mix: длина − 1 | 0..15 → 1..16 шагов таблицы |
| 12 | 7..4 | FM: длина − 1 | |
| 13 | 3..0 | Env FM: длина − 1 | |
| 13 | 7..4 | резерв | 0 |
| 14, 15 | | запас | 0 |

У выключенного эффекта его байты не смотрятся (нули). Адрес строки в странице FX: `FX × 512 + строка × 16`.

## Заголовок FX (на весь FX, отдельная страница рядом с таблицами)

| Поле | Значения |
|---|---|
| длина FX (строк) − 1, цикл (строка) | как у инструмента |
| форма свипа — номер таблицы | 0..255 (таблица из 16 точек кривой) |
| стартовая фаза свипа | 0..255 (128 — середина цикла), берётся на новой ноте |
| флаги | бит 0 — не перезапускать свип на новой ноте |

Имя FX — в странице трека.

## Таблица (16 байт)

Смысл значения — по эффекту, который её играет:

| Эффект | Значение шага |
|---|---|
| SID | громкость 0..15; 0 — тишина. Итог = уровень ЦАП(шаг) × уровень ЦАП(громкость ноты), ближайший уровень AY |
| Sync (бузер) | форма огибающей 0..15 — пишется в R13 (перезапуск огибающей) |
| FM | сдвиг тона со знаком: полутоны или единицы периода (флаг в байте 0) |
| Env FM | сдвиг периода огибающей со знаком: полутоны или единицы периода |
| форма свипа | точка кривой 0..255: 0 — скважность min, 255 — max; RP сглаживает между точками |

Таблицы играются с шага 0 по `длина − 1`, по кругу. У нового трека — пресет таблиц с подписями (меандр SID `15 0`,
треугольник, синус, пилы и т.п.).

## Пакет `ROW` (в карту, `#C1`)

| Байт | Что |
|---|---|
| 0 | код `ROW` |
| 1 | канал 0..2 (чип — выбран `#FF` / `#FE`) |
| 2..15 | строка FX, байты 0..13 |
| 16 | форма свипа — номер таблицы (из заголовка FX) |
| 17 | стартовая фаза свипа (из заголовка FX) |
| 18 | бит 0 — не перезапускать свип (из заголовка FX) |

Всего 19 байт. Шлёт плеер **только когда строка FX канала сменилась**; иначе карта играет последнюю.
Новая нота — пакет `RESET` (маска каналов): таймеры, шаги таблиц и свип (если не «не перезапускать») — с начала.
Таблицы — пакетом `TABLE` при загрузке трека (все используемые) и при правке (одна).

## Как карта это играет (кратко, подробно — `doc/bitphase-fx.md`)

- Период таймера = период тона канала × `2^(−полутоны/12)` + сырой детюн; единица — 8 тактов AY (как у тона).
  Таблица из 2 шагов при детюне 0 — ровно в ноту.
- SID — только когда у канала нет огибающей; Sync и Env FM — когда огибающая включена. На канале SID или Sync, не оба;
  Sync и Env FM — на одном канале чипа (огибающая у чипа одна).
- PWM (длина Mix = 2): шаг 0 длится `2P · d`, шаг 1 — `2P · (1 − d)`; `d` — от свипа (фаза → форма → между min и max),
  округлённая до ступени.

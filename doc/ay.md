# AY-3-8910 / YM2149 — шпаргалка

Источники: `docs/ay_ports.txt`, `docs/ay8910.pdf`, `docs/AY-3-8910.png`,
`docs/8910.jpg`, `docs/microchip_ay8930.pdf` (AY8930 — расширенный режим, нам
пока не нужен).

## Порты ZX

| Порт | Назначение |
|---|---|
| `#FFFD` (65533) | выбор регистра (OUT), чтение регистра (IN) |
| `#BFFD` (49149) | запись в выбранный регистр |

TurboSound: выбор чипа — запись в `#FFFD` значения `#FF` (чип 0) или `#FE`
(чип 1), дальше работа как обычно.

## Регистры

| Рег | Бит | Что |
|---|---|---|
| R0,R1 | 12 | период тона A (R1 — старшие 4 бита) |
| R2,R3 | 12 | период тона B |
| R4,R5 | 12 | период тона C |
| R6 | 5 | период шума (общий на 3 канала) |
| R7 | 8 | микшер: 0 = тон A, 1 = тон B, 2 = тон C, 3..5 = шум A..C (0 = включено, 1 = выключено); 6, 7 — направление портов IOA/IOB |
| R8..R10 | 5 | громкость A..C: биты 0..3 — уровень, бит 4 — играть огибающей |
| R11,R12 | 16 | период огибающей (R12 — старший) |
| R13 | 4 | форма огибающей; **любая запись перезапускает огибающую** |
| R14,R15 | 8 | порты IOA, IOB |

Частоты (такт чипа F = 1.75 МГц на Пентеве/TS, 1.7734 МГц на фирменном 128):
- тон: F / (16 × период);
- огибающая: F / (256 × период) — частота шага, полный цикл ещё ×16 (или ×32
  для треугольника).

## Формы огибающей (R13)

Биты: 3 — Continue, 2 — Attack, 1 — Alternate, 0 — Hold.

| R13 | Вид | | R13 | Вид |
|---|---|---|---|---|
| 0..3 | `\___` | | 8 | `\\\\` пила вниз |
| 4..7 | `/___` | | 9 | `\___` |
| | | | A | `\/\/` треугольник |
| | | | B | `\‾‾‾` |
| | | | C | `////` пила вверх |
| | | | D | `/‾‾‾` |
| | | | E | `/\/\` треугольник |
| | | | F | `/___` |

Циклические — 8, A, C, E. Только они имеет смысл «огибающая как нота»
(период огибающей подбирается под период тона: тон/16 для пилы, тон/32 для
треугольника).

## Что важно для плеера и трекера

- Запись в R13 рвёт фазу (щелчок) — писать только когда форма задана явно или
  нужен ретриггер (в FTC — команда 500).
- Шум один на чип. Если шум задают несколько каналов, побеждает последний
  обработанный (во всех трекерах порядок A, B, C).
- Периоды тона — 12 бит. Всё, что выше, отбрасывается чипом; плееры на этом
  экономят (флаги в старших битах смещений, см. FTC).
- Громкость нелинейная (близка к логарифмической). Таблица громкости в
  трекерах — «громкость канала × амплитуда сэмпла», см. `doc/trackers.md`.

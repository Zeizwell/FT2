## Особенности

| Возможность | Где есть |
|---|---|
| Транспозиция в позиции | ST, STP, PSM, SQT (ещё громкость и флаги в позиции), FTC (HGT 0..255) |
| Темп в позиции / паттерне | SQT (позиция), PSM (паттерн) |
| Конец без цикла | PSM |
| Сэмпл без цикла | ST, STP, ASC, PSM |
| Выход из цикла сэмпла | ASC |
| Выход из цикла орнамента | PSC |
| Орнамент только с накоплением | ASC |
| Шум в орнаменте | ASC, FTC |
| Огибающая в сэмпле (маска, смещение) | PT3, FTC, ASC; в PSM амплитуда 16..31 = огибающая |
| Накопление тона / шума / громкости в сэмпле | PT3, FTC, ASC |
| Портаменто по времени, а не по скорости | ASC (удобнее музыканту, правильно работает между паттернами) |
| Портаменто из текущего отклонения | ASC, VT (новое 3xxx), PT 3.6+ частично |
| Глисс со стоп-командой | STP, PT2 |
| Период огибающей: только старший / младший / от ноты | PSM |
| Огибающая как нота | VT (режим отображения), FT (автоогибающая, 8 соотношений) |
| Ретриггер огибающей и тона | FTC (500) |
| Сэмпл 0 «W» | PT3 (формат позволяет) |
| TurboSound | VT (пара модулей + `02TS`), PT 3.7 (+98) |

Таблицы нот: в PT3 их 4, полезны две (подробно в `pt3.md`):
- #1 — для импорта старых форматов, 1.7734 МГц;
- #2 — 1.75 МГц, наш случай (Пентева/TS).

FTC с версии 1.07 — ST-таблица плюс своя для 1.75 МГц.

Таблица громкости PT 3.5+ и FTC: `(i*j+7) div 15`. PSM, STP, SQT, GTR —
вычитание (15 − громкость) из амплитуды.

## Что брать при конвертации в FT2

Импорт без потерь требует:
- транспозиции в позиции (ST, STP, PSM, SQT, FTC);
- длинных сэмплов и орнаментов (FTC — 80, VT — орнаменты до 255);
- шума в орнаменте (ASC, FTC);
- ретриггера (FTC).

Остальное укладывается в модель PT3/VT.

## Горячие клавиши

### Vortex Tracker II (PC — ближе всего к нам: у нас PS/2)

**Ноты** — две клавиатурные октавы, «пианино»:

```
 2 3   5 6 7   9 0   =        S D   G H J   L ;
Q W E R T Y U I O P [ ]      Z X C V B N M , . /
```

- Shift+нота — октава выше; Shift+Ctrl+нота — ниже.
- A — R--, K — `---`.
- Numpad 1..8 — октава.

**Навигация:**
- стрелки;
- PgUp/PgDn;
- Home/End;
- Ctrl+←/→ — по колонкам;
- Ctrl+PgUp/PgDn — верх / низ;
- F9..F12 — четверти паттерна;
- колесо мыши.

**Выделение:**
- Shift+стрелки;
- Ctrl+A;
- мышь с левой кнопкой;
- Shift+клик.

**Правка:**
- Del — очистить;
- BackSpace — удалить строку трека; Ctrl+BackSpace / Ctrl+Y — строку паттерна;
- Ins — вставить строку трека; Ctrl+I — строку паттерна;
- Numpad / и * — сжать / растянуть паттерн вдвое.

**Буфер:**
- Ctrl+C / X / V;
- Ctrl+Alt+V — вставка без затирания пустыми.

**Транспонирование:**
- Numpad ± — полутон;
- Ctrl+Numpad ± — октава;
- Alt+←/→ — поменять каналы местами.

**Проигрывание:**
- F5 — сонг с позиции;
- F6 — сонг с начала;
- F7 — паттерн со строки;
- F8 — паттерн с начала;
- Esc — стоп;
- Enter (держать) — играть от курсора;
- Ctrl+L — цикл.

**Прочее:**
- Space — автошаг; Ctrl+0..9 — шаг;
- Numpad 0 / Ctrl+E — автоогибающая;
- Ctrl+T — трек-менеджер;
- Ctrl+Alt+T — глобальное транспонирование;
- Ctrl+M — заглушить сэмплы;
- \` — ордер ⇄ паттерн;
- Alt+BackSpace / Alt+Enter — undo / redo;
- Ctrl+S, Ctrl+O.

**Правая кнопка** — меню:
- то же, что клавиши;
- Split pattern;
- Pack pattern.

### Fast Tracker 1.15f (ZX: CS = Caps Shift, SS = Symbol Shift)

**Меню и общие:**
- SS+A — сэмплы;
- SS+I — имиджи;
- SS+O — ордер;
- SS+L / SS+S — загрузить / записать;
- SS+T — таблица нот;
- SS+E / D / F — автоогибающая и её соотношение;
- SS+R, SS+6 / 7 — автоскролл и шаг;
- SS+1..3 — вкл/выкл каналов; SS+4 — соло;
- SS+8 / 9 — темп;
- SS+N / M — пред. / след. паттерн;
- SS+J / K — длина паттерна;
- SS+Y — играть с позиции; SS+U — с начала; SS+P — паттерн.

**Паттерн:**
- ноты ZSXDCVGBHNJM, CS+нота — октава выше; 1..8 — октава;
- R — R--;
- L — стереть ноту; CS+L — ноту с параметрами;
- Enter — играть от курсора;
- CS+2 — начало; CS+3 / CS+4 — быстро вниз / вверх;
- CS+SS — по каналам;
- SS+C / SS+V — копировать / вставить канал от курсора;
- SS+Q / CS+0 — удалить строку; SS+W — вставить строку;
- SS+X / SS+Z — транспонировать канал от курсора.

**Ордер:**
- W / S — ±1;
- 1 / 2 — начало / конец цикла;
- 0 — обнулить.

## Бинды FT2 по умолчанию — предложение (решает пользователь)

Основа — VT II: клавиатура у нас PC (PS/2), музыканты знают VT. Механизм —
`doc/architecture.md`, раздел про бинды: действия + таблица, свои — из
`ft2.ini`.

Уже в коде (`srs/patview.asm`, `Hotkeys`):

| Клавиша | Действие | В VT |
|---|---|---|
| ↑ ↓ PgUp PgDn | строки, ±16 | так же |
| ← → / Tab, Shift+Tab | каналы | Tab — по окнам |
| F5 | сонг с текущей позиции | так же |
| F6 | сонг с начала | так же |
| F7 | паттерн по кругу с текущей роу | так же |
| F8 | паттерн по кругу с начала | так же |
| Esc | стоп | так же |
| Space | — (автошаг, когда появится) | автошаг |
| Ctrl+E | открыть Env чипа | автоогибающая |
| Ctrl+T | полоса времени (отладка) | трек-менеджер |

**Решено (пользователь):** пока как в VT, потом поменяем, если что. Ctrl+E и Ctrl+T пока заняты своим — уйдут, когда появятся автоогибающая и трек-менеджер.

Предлагаю взять из VT без изменений:
- ноты, A (R--), K (`---`), Numpad 1..8;
- Del, BackSpace, Ins с Ctrl-вариантами;
- Ctrl+C / X / V, Numpad ± (с Ctrl — октава);
- Shift+стрелки — выделение;
- Ctrl+0..9 — шаг;
- \` — ордер ⇄ паттерн;
- правая кнопка — контекстное меню.

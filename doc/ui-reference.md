# Интерфейсы трекеров — что где (по скриншотам пользователя, 2026-10-05)

Bitphase подробно — в `bitphase.md`. Здесь — верх экрана, настройки, редакторы.

## Vortex Tracker II

**Вкладки окна модуля:** `Patterns` `Samples` `Ornaments` `Options` `Info`.

**Панель над паттерном (вкладка Patterns)**, слева направо:

| Группа | Что |
|---|---|
| Load / Save | кнопки |
| Pattern | номер паттерна `0` [▲▼] |
| Length | длина `40` [▲▼] |
| Speed/BPM | `3 / 244` [▲▼] — скорость и пересчёт в BPM |
| Octave | `3` [▲▼] |
| Auto Step | кнопка-переключатель + число `0` [▲▼] |
| Auto Env | кнопка + соотношение `1 : 1` (две кнопки-числа) |
| Tone Table | номер таблицы `2` [▲▼] |
| TS | кнопка TurboSound (второй чип) |

Ниже:
- строка «название … by автор»;
- **ордер — горизонтальная полоса**: номера паттернов в ячейках, текущая позиция
  выделена, повтор отмечен, ниже полоса прокрутки;
- **шапка каналов:**
  - `Auto [4]` — шаг ввода;
  - `Channel A` `T` `N` `E` `S` — заглушить в канале тон / шум / огибающую, соло.
  
  Так же для B и C.

## Arkos Tracker

**Верхняя панель:**
- меню `File` `Edit` `Tools` `Help`;
- транспорт: play song, play pattern, play from cursor, stop;
- `Octave 3` [−+];
- `Speed 6 (125 bpm)`;
- кнопки подпесен `1 2 3 4`;
- время `0:00 / 0:07`.

Под ней:
- **полоса ордера блоками** («Start», номер позиции крупно);
- окна каналов с номерами `1` `2` `3` сверху.

**Слева — список инструментов:** `00 Silence (read-only)`, `01 Beep`… Над ним
кнопки-значки: инструменты, арпеджио, питчи, …

**Над паттерном** — строка инструментов редактора:
- запись (●);
- шаг `[1] −+`;
- выбор, что показывать в колонке: `v: volume`;
- подсказка по колонке под курсором: «Column for the note and octave».

**Паттерн:** номер роу слева, у каналов свои заголовки с кнопками.

**Внизу — клавиатура пианино** (ноты мышью, видно играющие), кнопки `Play!`, `Mono`.

## Bitphase (полный экран)

- **Верх:**
  - меню;
  - транспорт;
  - Octave, Step;
  - галочки `Auto Env`, `Env as Note`;
  - громкость.
- **Слева:** ордер узкой колонкой.
- **В центре:** окно паттерна чипа.
- **Справа:** список инструментов (номер, имя), за ним панель редактора инструмента:
  - вкладки `Instruments` / `Tables` / `Details`;
  - ряд инструментов вкладками (`01 Instrument 01`, `02 tone + env`…);
  - кнопки Add / Save / Load / Presets;
  - Name, Color;
  - режимы `Mixer` / `Timer Effects` / `Sample`, `Classic`;
  - графики столбиками: `Volume` (зелёные столбики по строкам), `Waveform`,
    `Tone parameters` — у каждого свой цикл и масштаб;
  - внизу `Preview playground`: Inst, Envelope, Shape, Noise, Table, Volume, Note
    и ▷ — проиграть инструмент без паттерна.

## Общее, что повторяется

- **Транспорт:** плей сонга, плей паттерна, с курсора, стоп — у всех вверху.
- **Октава, шаг, скорость** — у всех вверху. Скорость с пересчётом в BPM — у VT и Arkos.
- **Таблица нот:**
  - VT — числом в панели;
  - Bitphase — в настройках чипа;
  - FT — переключателем (SS+T).
- **TurboSound / второй чип:**
  - VT — кнопка TS;
  - Bitphase — «песня на чип», несколько песен в проекте.
- **Маски каналов** T / N / E / S (VT) — заглушить тон / шум / огибающую / соло прямо
  в шапке канала.
- **Редакторы инструментов и орнаментов:**
  - VT — отдельными вкладками;
  - Bitphase и Arkos — панелью рядом с паттерном;
  - FT1 — отдельными экранами.
- **Прослушать инструмент без паттерна:**
  - Bitphase — Preview playground;
  - Arkos — клавиатура пианино.
- **Время трека** — Arkos (`0:00 / 0:07`).

## Автоогибающая (Vortex Tracker II, исходник)

- Стандартные соотношения A:B (`StdAutoEnv`, `main.pas`): `1:1, 3:4, 1:2, 1:4, 3:1,
  5:2, 2:1, 3:2`. Кнопка «:» перебирает их по кругу.
- A и B по отдельности — кнопки по бокам, каждое число 1..9 по кругу.
- Период огибающей (`CHILDWIN.PAS`) = период ноты × A / B:
  - / 16 для пилы (формы 8, 12);
  - / 32 для треугольника (10, 14);
  - другие формы не трогаются.

## Редактор сэмплов Vortex Tracker II (вкладка Samples)

**Сверху — полоса всех сэмплов 1..V:**
- в каждой ячейке маленький график громкости;
- красная точка — сэмпл используется в модуле;
- текущий выделен, внизу прокрутка.

**Тестовая строка:**
- `....|..|C-4 1F.F ....` — период огибающей | шум | нота, сэмпл, огибающая,
  орнамент, громкость | команда;
- кнопки Load / Save. Нота с клавиатуры играет сэмпл с этими параметрами.

**Строки сэмпла** (номер слева, область цикла подсвечена синим, за длиной — серые `...`):

| Колонка | Пример | Что |
|---|---|---|
| маски | `TN.` `T.E` `T..` | тон / шум / огибающая включены (буква) или нет (`.`) |
| тон | `+001.` | смещение тона со знаком; после него `.` или `^` — накопление |
| шум / огибающая | `+00(00).` | смещение, в скобках итоговое значение; знак накопления |
| громкость | `F` `B▼` | громкость; `▼` / `▲` — слайд вниз / вверх |
| график | `███████` | полоса длиной в громкость — видно форму целиком |

**Справа:**
- Sample `1`[▲▼];
- Length `0E`[▲▼];
- Loop `07`[▲▼];
- Copy / Paste;
- Unloop, Clear;
- `<<` `>>` — соседний сэмпл.

Под ними — **библиотека сэмплов** в виде дерева папок: `[Clicks]` `[FX]` `[HitHats]`
`[Keys]` `[Kicks]` `[Noises]` `[Sequences]` `[Snares]` `[Synths]` — то, что мы хотим
(папка на диске, свои подпапки).

Вверху справа — Mute / Solo.

## Сравнение с Bitphase

| | VT | Bitphase |
|---|---|---|
| строка | все параметры строки в одной текстовой строке + полоса громкости | таблица с колонками-значками + отдельные графики (Volume, Waveform, Tone) |
| цикл | один на весь сэмпл (Loop + Length) | у каждого макроса свой цикл и длина |
| ввод | с клавиатуры, как в паттерне | мышью по графикам и ячейкам |
| прослушать | тестовая строка + нота с клавиатуры | Preview playground |
| выбор | полоса мини-графиков всех сэмплов | вкладки с именами |

Для FT2 ближе VT: формат строки у нас как в FTC — одна строка, один цикл. Экран —
текст, ввод с клавиатуры, полоса громкости рядом со строкой.

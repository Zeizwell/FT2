# Команды паттерна — разбор и наш набор

Источники: `doc/formats/pt2.md`, `pt3.md`, `ftc.md`, `doc/bitphase.md`,
`trackers/vt/Tracker manual.txt` (VT II). STC — команд нет (только огибающая и орнамент
в треке); ASC, SQT — разобрать, если дойдём до их импорта.

## Как команда лежит в нашей клетке

Две команды на клетку (`CH_CMD` +6, +8), по 2 байта:
`байт 0 = код << 4 | задержка (0..F)`, `байт 1 = параметр`. 0,0 — пусто.
На экране 4 hex: `NDPp` — как в VT. Коды — только именами `CMD_*` (`sdk/plugin.asm`):
код меняется в одном месте, плеер, импорт и экспорт берут имя.

## Тонкости

- **Задержка (D)** у PT3/VT — раз в сколько тиков применять шаг. У FTC и PT2 её нет:
  импорт ставит задержку 1.
- **Глисс FTC** — шаг словом (±32767), у нас параметр байт: большие шаги обрезаются
  (импорт помечает потерю).
- **Портаменто:**
  - PT3/VT — шаг в периодах за D тиков;
  - FTC — «скорость» байтом, разницу считает плеер при ноте;
  - PT2 — компилятор сам пишет шаг и разницу (и ошибается на первой ноте паттерна);
  - VT 3.6+: новое толкование 3xxx — портаменто от текущего отклонения, работает и без
    ноты в строке.
- **PT3 в редакторе** — одна команда на строку канала, формат позволяет больше. У нас — две.
- **Стоп:** все слайды тона (1, 2, 3) снимаются командой с параметром 0, нотой или R--.
  Команда 6 снимает слайды, слайды снимают 6.
- **Шум** — не команда, а колонка чипа (как у PT3 трек B и Bitphase NO). Команда FTC `#EF n`
  импортом переносится в колонку.

## Что есть в форматах экспорта

| | PT3 | FTC |
|---|---|---|
| 1, 2 (глисс) | да | да (без задержки) |
| 3 (портаменто) | да | да (только скорость) |
| 4, 5 (позиции) | да | нет |
| 6 (вкл / выкл) | да | нет |
| 9, A (огибающая) | да | нет |
| B (скорость) | да | да |
| ретриггер | нет | да |
| остальное (7, 8, детюн, арпеджио, вибрато) | нет | нет |

Чего нет в формате — компилятор пропускает и пишет в отчёт о потерях.

## Предложение: наш набор

Основа — номера VT (их знают музыканты, PT3 и импорт уже на них): 1–6, 9, A, B — как есть.
Свободные коды: **7, 8, C, D, E, F**. Кандидаты (из Bitphase и FT):

| Код | Команда | Откуда | Зачем |
|---|---|---|---|
| 7 | задержка ноты | Bitphase `7` | частая, простая |
| 8 | слайд громкости | Bitphase `8` | частая |
| C | ретриггер огибающей и тона | FT `500` | импорт FTC без потерь |
| D | детюн | Bitphase `D` | расстройка канала |
| E | арпеджио | Bitphase `A` (у нас A занят огибающей) | |
| F | вибрато | Bitphase `V` | |

Арпеджио и вибрато делаются и инструментом / орнаментом. Можно их не брать, а `F` оставить под
расширенные команды (`F` + подкод в задержке — ещё 16 команд).

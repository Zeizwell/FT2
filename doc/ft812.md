## Что умеет FT812 (по даташиту)

- экран до **800×600** (SVGA); 640×480 — с запасом;
- **1 МБ** своей памяти (RAM_G), кадрового буфера нет: картинку каждый кадр строит **список команд** (display list,
  RAM_DL 8 КБ), его собирает сопроцессор по командам `CMD_*` из FIFO;
- **текстовые форматы** `TEXT8X8`, `TEXTVGA` — сетка символов из RAM_G рисуется одной командой (8 точек за такт): на
  640×480 со шрифтом 8×8 — **80×60** знакомест (у TS-Config — 90×36);
- шрифты: встроенные (handle 16–34, в т.ч. сглаженные) и свои в RAM_G (handle 0–15);
- виджеты сопроцессора: `CMD_BUTTON` (объёмная кнопка), ползунки, скроллбары, переключатели, градиенты, часы и т.п.;
  прозрачность (альфа), ножницы (scissor), точки / линии / прямоугольники;
- **`LINE_STRIP`** — линия по точкам: осциллографы рисуются линией в полном разрешении (без битмапов и спрайтов);
- JPEG / PNG, видео — не нужно.

## Как ляжет на FT2

1. **Ядро не меняется**: плеер, данные трека, редакторы, бинды, поля (`srs/fields.asm`), окна, строка ввода,
   поле числа, кнопка.
2. **Меняется слой вывода**: вместо текстовой страницы TS-Config — сетка символов + атрибутов в RAM_G (`TEXTVGA`
   или свой шрифт), поверх — команды: кнопки, рамки, тени, градиенты шапки, окна с прозрачностью, осциллографы
   линиями. Вид «как MilkyTracker» — штатными средствами чипа.
3. **Обмен** — SPI Евы (`#57` / `#77`), можно DMA TS-Config (RAM → SPI). Вся сетка 80×60×2 ≈ 9.6 КБ — слать не
   каждый кадр: список команд + изменённые строки (паттерн при проигрывании).
4. **Осциллографы** — точки волны (от плеера / от RP Trinity) → `LINE_STRIP`, никакой картинки по шине.

## Условия

- нужен VDAC2 / FT812 у пользователя — у большинства Ев его нет: **вторая версия вывода, не замена**;
- **правило уже сейчас:** стандартные элементы (окно `srs/window.asm`, кнопка `srs/button.asm`, поле числа
  `srs/spin.asm`, строка ввода `srs/textin.asm`, скроллбар, список) рисуют **только через свои процедуры** — тогда под
  FT812 переписывается этот слой, а не все экраны;
- разрешение и раскладка 80×60 — свои раскладки экранов (больше места: паттерн шире / выше).

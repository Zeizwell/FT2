# maxYMiser (Atari ST, gwEm): дамп треков — `convert/mym/`

Сделано раньше (коммиты `1cb07da`, `253c5a8`), в доки не попало — записано 2026-10-25, чтобы не искать заново.

- `convert/mym/mym_dump.pl` — `.mys` (песня) / `.myv` (голоса) или **SNDH, выгруженный из maxYMiser** (сырые файлы
  внутри: плеер, 3 смещения, `.myv`, `.mys`) -> текст: песня (длина, повтор, скорость, таймер), ордер (4 трека),
  паттерны (нота, инструмент, громкость, буквы эффектов), инструменты, последовательности.
- ICE! 2.40 распаковка (порт unice68 из sc68); старый SNDH maxYMiser 2006 (8 нулей вместо тегов `MYM`); `-u` —
  только распаковать.
- Формат — по исходнику плеера автора: github.com/gwEm303/maxYMiser_replay (`replay.s`, `trakdata.s`, `sndh.s`:
  `gen_patterntab`, `parsetracker`, `parsefxcolumn`).
- **Дампы музыки пользователя** — `convert/mym/dumps/*.txt` (14 треков, в git не добавлены).
- Эффекты паттерна (буквы) — таблица `%eff` в начале скрипта: таймер `I`, бузер `C` / `W`, PWM `7` / `8` / `9`,
  арпеджио `A` / `X`, портаменто / слайды / вибрато `P` / `H` / `V`, диджи `G` / `R` и т.д.

**Дальше (2026-10-25, цель пользователя — живые треки с FX в FT2):** конвертер `mym -> .ft2`: ноты, ордер, паттерны —
как есть; эффекты maxYMiser -> наши FX / орнаменты / команды; что не ложится — в лог потерь, доделывается руками.

# Fast Tracker (.ftc) — откомпилированный модуль

Источники:
- `docs/008! FTplayer.t` = `players/FT1-15player_src.asm` (CP866) — плеер
  1.15 (Orion/DR);
- `docs/006! FT_help.t` — справка FT 1.15f;
- `Trackers limitations.ru.txt`.

Формата в тексте нет — всё ниже восстановлено по коду плеера и проверено на
`Modules for test/Fast Tracker/BLIN.ftc`. Смещения от начала модуля, слова
младшим вперёд. В файле смещения относительные, плеер при инициализации
прибавляет адрес модуля. Повторный инит проверяет, что старший байт уже ≥ `#40`.

## Заголовок

| Смещ | Длина | Что |
|---|---|---|
| +#00 | 8 | `Module: ` |
| +#08 | 42 | название |
| +#32 | 1 | таблица нот: 2 = 1.75 МГц, иначе классика (ST) |
| +#33 | 18 | `Fast Tracker v1.07` и т.п. |
| +#45 | 1 | темп |
| +#46 | 1 | позиция цикла |
| +#47 | 4 | ? (в BLIN `00 00 01 00`), плеер не читает |
| +#4B | 2 | смещение таблицы паттернов |
| +#4D | 4 | ? (в BLIN `#00E5`, `#00FB`), плеер не читает |
| +#52 | 32×2 | смещения сэмплов 0..31 |
| +#92 | 33×2 | смещения орнаментов («имиджей») 0..32 |
| +#D4 | ? | ордер: пары (паттерн, транспозиция HGT). Байт паттерна с битом 7 — конец, переход на цикл |

После ордера может лежать произвольный текст (в BLIN — привет автора).

Таблица паттернов — по 6 байт (треки A, B, C), конец — `#FFFF`.

Транспозиция HGT (0..255) прибавляется к каждой ноте позиции.

## Трек

Цепочка `ADD` в плеере пересчитана в диапазоны:

| Код | Параметры | Что |
|---|---|---|
| `#00..#1F` | | сэмпл 0..31 |
| `#20..#2F` | | громкость 0..15 (строка таблицы громкости) |
| `#30` | | R-- (канал молчит до следующей ноты) — **конец строки** |
| `#31..#3E` | Lenv, Henv | огибающая формы x, период (младший первым). Пишется R13 (ретриггер) |
| `#3F` | | выключить огибающую из сэмпла |
| `#40..#5F` | | ждать n строк до следующего чтения — **конец строки** |
| `#60..#CB` | | нота 0..107 (+HGT) — **конец строки** |
| `#CC..#EC` | | орнамент 0..32 |
| `#ED` | Lsl, Hsl | глисс (1xx/2xx), шаг — слово со знаком |
| `#EE` | speed | портаменто (3xx) к ноте этой строки |
| `#EF` | n | смещение шума (4xx); `#FE` — ретриггер тона и огибающей (500) |
| `#F0..#FF` | tempo | темп (Fxx) |

Строка трека всегда кончается нотой, `#30` или `#4x`. Пустых байтов на
пустые строки нет. Конец паттерна — `#FF` в начале строки трека A.

Справка FT: команда F00 «глушит громкость до её изменения» — в треке это,
видимо, громкость 0 (`#20`). Сверить на модулях.

## Сэмпл

| Смещ | Что |
|---|---|
| +0 | = end (копия +2). Плеер не читает; во всех тестовых модулях равен +2 — длина для редактора / декомпилятора |
| +1 | позиция цикла |
| +2 | последняя строка (end), длина = end+1 |
| +3 | строки по 5 байт |

Строка сэмпла:
- байт 0 — шум: бит 7 — накапливать, бит 6 — шум выкл, биты 4..0 — смещение
  шума (+ шум трека + шум орнамента);
- байты 1..2 — смещение тона, слово:
  - бит 15 — накапливать, бит 14 — тон выкл;
  - 12 бит по модулю 4096, прибавляется к периоду;
- байт 3 — громкость:
  - бит 7 — накапливать смещение огибающей, бит 6 — огибающая в строке;
  - бит 5 — слайд громкости, бит 4 — вниз;
  - биты 3..0 — амплитуда, слайд ограничен ±15;
- байт 4 — смещение огибающей, знаковый байт; период огибающей = базовый − смещение.

Пример (BLIN, сэмпл 1): `40 00 00 0F 00` ×4, `40 00 00 3F 00` — без шума,
тон без смещения, громкость 15, в последней строке затухание.

## Орнамент («имидж»)

| Смещ | Что |
|---|---|
| +0 | = end (копия +2), плеер не читает — длина для редактора / декомпилятора |
| +1 | цикл |
| +2 | end |
| +3 | строки по 2 байта |

Строка орнамента:
- байт 0 — шум: бит 7 — накапливать шум, бит 6 — накапливать ноту, биты 4..0 —
  смещение шума;
- байт 1 — смещение ноты в полутонах (знаковое).

Пример (BLIN, орнамент 2): `07 00 07`, строки `00 FB` `00 FB` `00 00` `00 00`
`00 03` `00 03` `00 0C` `00 0C` — аккорд −5, 0, +3, +12 по два тика.

## Ограничения (справка FT 1.15f)

| | |
|---|---|
| паттернов | 32 |
| строк | 1..64 |
| позиций | 256, у каждой транспозиция 0..255 |
| сэмплов | 32 (1..W в редакторе, 0 = текущий), длина до 80 |
| орнаментов | 32 + пустой, длина до 80 |
| темп | 3..255 |
| нот | 8 октав (в формате до 108) |
| модуль | до 16384 байт |

Таблица громкости — как в PT3 3.5+.

## Колонки редактора

```
ENV  NOTE DATA COM
012D A-4  W83A 123
```

- ENV — период огибающей;
- DATA — сэмпл, форма огибающей, имидж, громкость (0 = прежнее значение);
- COM — команда и параметр:
  - 1xx / 2xx — глисс вверх / вниз;
  - 3xx — портаменто;
  - 4xx — шум;
  - 500 — ретриггер;
  - Fxx — темп;
  - F00 — заглушить.

## Отличия, которые теряются при переводе в PT3

- Ретриггер (в PT3 нет).
- Огибающая с сэмплом, где огибающая запрещена маской: FTC не пишет R11/R12,
  PT3 пишет.
- 32 сэмпла и 33 орнамента против 31 и 16.
- Длины сэмплов и орнаментов больше 64.
- Транспозиция в ордере.
- Шум в орнаменте.

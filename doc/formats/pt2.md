# Pro Tracker 2.x (.pt2) — откомпилированный модуль

Источник: `formats/pt2_format.txt` (VfNG, Echo #2, 1996, с исходником плеера).
Смещения — от начала модуля, слова — младшим вперёд.

## Заголовок

| Смещ | Длина | Что |
|---|---|---|
| +0 | 1 | темп (DELAY) |
| +1 | 1 | число позиций |
| +2 | 1 | позиция цикла |
| +3 | 32×2 | смещения сэмплов (0 не описан — им глушат канал) |
| +67 | 16×2 | смещения орнаментов (0 = нет орнамента) |
| +99 | 2 | смещение таблицы паттернов |
| +101 | 30 | название |
| +131 | ? | ордер: номера паттернов, конец `#FF` |

Таблица паттернов: по 6 байт (смещения треков A, B, C), конец — `#0000`.

## Трек

Плеер разбирает байт цепочкой `ADD A,n / JR C` (`ADD #20`, `#60`, `#10`,
`#10`, `#40`, `#10`, потом `INC A`). Диапазоны (пересчитаны из цепочки):

| Код | Что |
|---|---|
| `#E0..#FF` | сэмпл 0..31. 0 — выключить канал и конец строки |
| `#80..#DF` | нота 0..95 (8 октав) |
| `#70` | конец строки |
| `#71..#7E` | огибающая формы 1..14, дальше 2 байта периода |
| `#7F` | выключить огибающую |
| `#60..#6F` | орнамент 0..15 |
| `#20..#5F` | пропуск 0..63 строк до следующего изменения |
| `#10..#1F` | громкость 0..15 |
| `#0F` | + 1 байт: темп |
| `#0E` | + 1 байт: глисс (знак: 128..255 «+», 0..127 «-») |
| `#0D` | + 3 байта: портаменто (шаг, разница периодов слово). Компилятор ошибается, если нота — первая в паттерне |
| `#0C` | выключить команды |
| `#00..#0B` | + 1 байт: смещение шума |

Последние две строки — так по коду из статьи. Текст статьи их путает,
сверить на модулях из `Modules for test/Pro Tracker 2.xx`.

## Сэмпл

| Смещ | Что |
|---|---|
| +0 | длина |
| +1 | позиция цикла |
| +2 | строки по 3 байта |

Строка сэмпла:
- байт 0: биты 7..3 — шум 0..31, бит 2 — знак смещения тона (1 = «-»), бит 1 —
  маска тона, бит 0 — маска шума;
- байт 1: биты 7..4 — амплитуда, биты 3..0 — старшие биты смещения тона;
- байт 2: младший байт смещения тона.

## Орнамент

`+0` длина, `+1` цикл, дальше по байту: смещение 0..63 полутонов, бит 7 — знак
(1 = «-»).

## Порядок в плеере

Счётчик темпа уменьшается каждое прерывание. При 2 читается канал A (и конец
паттерна), при 1 — B, при 0 — C, затем всё применяется. Нагрузка разнесена на
три кадра.

## Ограничения

Паттернов 32 (по таблице), строк 64, позиций 255, сэмплов 31 (+0), орнаментов
15 (+0). По сравнению с PT3 нет маски огибающей и смещения огибающей в сэмпле,
нет накопления тона, шума и громкости. Конвертируется в PT3 без потерь.

# Pro Tracker 3.x / Vortex Tracker II (.pt3) — откомпилированный модуль

Источники: `formats/pt_format.txt`, `pt34_format.txt`, `pt37_format.txt`
(Alone Coder, дополнения Sergey Bulba), `trackers/vt/Tracker manual.txt`,
`Trackers limitations.ru.txt`, `ZXTSPlayer.txt`, `History.txt`.
Все смещения — от начала модуля, слова — младшим байтом вперёд.

## Заголовок

| Смещ | Длина | Что |
|---|---|---|
| +0 | 13 | `ProTracker 3.` (VT II пишет `Vortex Tracker II 1.0 module: ` — играется как 3.6) |
| +13 | 1 | подверсия `'3'..'7'`: ≤4 — старая таблица громкости; 3 — старая таблица нот #0; ≥6 — новое портаменто |
| +14 | 16 | ` compilation of ` (с 3.7 — любой текст) |
| +30 | 32 | название, добито пробелами |
| +62 | 4 | ` by ` |
| +66 | 32 | автор |
| +98 | 1 | `#20`; в TS-модуле 3.7 — число паттернов N (паттерны второго чипа — N-1, N-2…) |
| +99 | 1 | таблица нот: 0 ProTracker, 1 SoundTracker, 2 ASM/PSC, 3 RealSound |
| +100 | 1 | темп (прерываний на строку) |
| +101 | 1 | song end — плеером не используется |
| +102 | 1 | позиция цикла |
| +103 | 2 | смещение таблицы паттернов (Psa_chn) |
| +105 | 32×2 | смещения сэмплов 0..31 (0 = нет; сэмпл 0 бывает только в связке `#Fx`) |
| +169 | 16×2 | смещения орнаментов 0..15 (орнамент 0 = пустой `0,1,0`) |
| +201 | ? | ордер: номер паттерна × 3, конец — `#FF` |

Первые 100 байт на звук не влияют: в демах там бывает мусор. Узнавать PT3 по
структуре, а не по строке.

## Паттерны

Таблица Psa_chn: на паттерн 6 байт — смещения треков A, B, C. Колонка шума
компилируется в трек B.

Длина паттерна задаётся только треком A: строки до `#00`.

## Трек — байт за байтом

| Код | Параметры | Что |
|---|---|---|
| `#00` | | конец трека |
| `#01` | delay, Lsl, Hsl | глисс (1xx/2xx). 3.7: delay=0 — постоянное смещение тона |
| `#02` | delay, Lmax, Hmax, Lsl, Hsl | портаменто (3xx); max в 3.6+ не используется |
| `#03` | offset | сэмпл с позиции (4xx) |
| `#04` | offset | орнамент с позиции (5xx) |
| `#05` | on, off | вибрато громкостью (6xy) |
| `#08` | delay, Lsl, Hsl | слайд огибающей (9xx/Axx) |
| `#09` | tempo | темп (Bxx) |
| `#10` | smp×2 | выключить огибающую, сэмпл, рестарт орнамента (3.7) |
| `#11..#1F` | Henv, Lenv, smp×2 | огибающая формы x-1, период (**старший первым**), сэмпл |
| `#20..#3F` | | смещение шума 0..31 (только трек B) |
| `#40..#4F` | | орнамент x |
| `#50..#AF` | | нота 0..95 — **конец строки** |
| `#B0` | | выключить огибающую |
| `#B1` | lines | пропуск строк; действует дальше, пока не задан другой |
| `#B2..#BF` | Henv, Lenv | огибающая формы x-1 без сэмпла |
| `#C0` | | R-- (звук выкл) — **конец строки** |
| `#C1..#CF` | | громкость |
| `#D0` | | конец строки без ноты |
| `#D1..#EF` | | сэмпл 1..31 |
| `#F0..#FF` | smp×2 | орнамент x + сэмпл (огибающая выключается) |

Параметры спецкоманд `#01..#09` лежат **после конца строки** (после ноты или
`#D0`/`#C0`), в обратном порядке. Плеер обрабатывает их через стек.

## Сэмпл

| Смещ | Что |
|---|---|
| +0 | loop |
| +1 | end (длина) |
| +2 | строки по 4 байта |

Строка сэмпла:
- байт 0: `sv +- N4 N3 N2 N1 N0 Em`
  - sv — слайд громкости, +- — вверх;
  - N4..0 — шум, либо смещение огибающей, если шум выключен (знаковое ±15);
  - Em — маска огибающей (1 = выкл).
- байт 1: `Nm ts ns Tm V3 V2 V1 V0`
  - маски шума и тона (1 = выкл);
  - ts/ns — накапливать смещение тона / шума-огибающей;
  - V — амплитуда.
- байты 2..3: смещение тона, слово со знаком.

Баг PT3, сохранённый в VT: при выключенном шуме смещение огибающей действует
даже без огибающей в канале.

## Орнамент

`+0` loop, `+1` end, дальше по байту — смещение в полутонах (знаковое).

## Ограничения

| | редактор PT3 | формат | VT II |
|---|---|---|---|
| паттернов | 42 (3.58+: 46, 3.69+: 48) | 85 | 85 |
| строк | 64 | память | 256 |
| позиций | 256 | 255 | 256 |
| сэмплов | 31 (длина 64) | 32 | 31 |
| орнаментов | 15 + пустой (длина 64) | 16 (длина 255) | 16 (255) |
| темп | 3(2)..255 | 1..255 | 1..255 |
| нот | 96 (C-1..B-8) | | |

Модуль для редактора на ZX: не больше `#3300` байт (`#4000` для cjf).

## Таблицы

- Нот четыре, по 96 слов. Полезны две:
  - #1 SoundTracker — 1.7734 МГц, ноты сдвинуты на тон вниз, B-2 фальшивит;
  - #2 — точно под 1.75 МГц (в 3.4r и раньше была другой!).
- Громкость, 3.5+: `Amp(i,j) = (i*j+7) div 15`. Ту же таблицу использует FTC.

## TurboSound (VT)

Два PT3 подряд плюс 16-байтный хвост:

```
'PT3!', размер модуля 1 (слово),
'PT3!', размер модуля 2,
'02TS'
```

Второй вариант — PT 3.7: байт +98 = N, см. выше.
